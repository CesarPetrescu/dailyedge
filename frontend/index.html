The contract

  • No auto-buy. This API has no order endpoint.
  • Alerts are trade plans, not guarantees.
  • Every fire must re-stamp with signal-bar ATR.
  • Backtests can reject; only the ledger can promote.

The loop

1

Scan

Rank names by relative strength, relative volume, and breakout proximity.

2

Arm

Store exact triggers in `armed_watchers.json`. No guessing while price is below trigger.

3

Fire

If crossed, re-measure volatility and build entry/stop/target using fresh data.

4

Referee

Pass/fail rules decide whether it is actionable, probation-only, or no-go.

5

Human

You decide. If taking it, tiny tryout size and stop first.

6

Record

Taken or skipped, every signal belongs in the notebook.

7

Grade

The evidence machine uses Wilson floor and compares against the baseline.

8

Promote/cut

Forward results decide playing time. Bad forward edge retires the rule.
